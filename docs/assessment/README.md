# 重识别风险评估（maskhub.assessment）

对已发布（掩码处理后）的数据集做**逐数据集**的重识别风险评估。只读，不修改在役策略、规则或数据；报告只输出聚合统计，**不含任何个体的原始取值**。

## 评估口径

对每个数据集：

1. 在清单（manifest）中声明准标识符（QI）列与敏感列。
2. 枚举 1 至 `max_combo_order` 阶的全部准标识符组合；对每个组合在**整表**上划分等价类（取值组合相同的行属于同一类），得到类规模分布、最小类规模（k-匿名口径）、类数。
3. 按可复现的抽样方案抽取目标行样本，估计三类风险并给出置信区间：
   - **唯一行占比（检察官模型）**：样本中类规模为 1 的行比例；
   - **小类行占比**：类规模低于 k 匿名底线（默认 5）的行比例；
   - **平均逐行风险（记者模型）**：样本行 `1/类规模` 的均值。
4. 列级**稀有度**：不同取值数、单现取值占比、出现 ≤3 次的稀有取值占比、缺失率。
5. **外部可获取信息**：在攻击者画像中声明哪些 QI 组合可从外部来源（公开登记册、历史泄露库、可交叉内部表等）获得。总体结论只对“外部可得组合”做最坏情况汇总；未声明时对全部组合兜底评估并明确标注。
6. 可选 `pop_fraction`（发布表占目标总体比例）：启用总体唯一性的泊松比率近似（量级估计，非精确个体概率）。
7. 声明了敏感列时，按每个组合输出聚合的 l-多样性（组内敏感取值种数最小值/均值、平均熵），不输出敏感取值。

### 置信区间

- 比例类指标（唯一行/小类行占比）：Wilson 得分区间，按 SRSWOR 做有限总体校正（FPC），保守地保证区间包含点估计。
- 均值类指标（1/k、总体唯一性）：固定种子的百分位自助法（默认 1000 次重采样）。
- 结论分级取各风险指标 **95% 置信区间上界**（默认阈值见清单示例），即保守口径。

### 抽样的可复现性

- 总体框：发布表物理行序（表头除外）。
- 方案：无放回简单随机抽样（SRSWOR），部分 Fisher–Yates 洗牌。
- 随机源：自研 SHA-256 哈希生成器，种子材料为 `seed | 数据集标识 | 用途 | 计数器`，不依赖 Python 的全局 RNG、不依赖行内容；第三方可用任何语言重新推导同一组索引。
- 抽样比例、上限、下限、种子、自助次数全部写入清单与报告；报告另附输入文件 SHA-256 与抽样索引 SHA-256。同清单、同输入字节复跑结果逐位一致（仅生成时间戳不同）。

## 用法

```bash
python -m maskhub.assessment \
  --manifest docs/assessment/manifest.example.json \
  --json-out reports/risk-2026-10-04.json \
  --md-out   reports/risk-2026-10-04.md
```

清单关键字段：

| 字段 | 说明 |
| --- | --- |
| `seed` | 固定随机种子（建议用评估日期或批次号） |
| `sample_fraction` / `sample_size_cap` / `min_sample_size` | 抽样比例与行数上下限 |
| `max_combo_order` | 枚举的 QI 组合最高阶数 |
| `bootstraps` / `confidence` | 自助重采样次数与置信水平 |
| `attacker.available_combos` | 外部可获取的 QI 组合，形如 `"birth_year+region"` |
| `attacker.pop_fraction` | 发布表占目标总体比例（可选） |
| `thresholds` | 高/中风险阈值与 k、l 底线 |
| `datasets[].quasi_identifiers` / `sensitive` | 列名须与表头完全一致 |

## 安全边界（设计约束）

- 不 import、不写入 `maskhub.policy` / `maskhub.rule` / `maskhub.store` 中的任何写路径；CLI 仅读取清单指向的数据文件。
- 渲染层只接收统计对象，拿不到原始行；测试强制断言已知个体取值不出现在 JSON/Markdown 报告中。
- 发现高风险时报告只给**加固方向**（泛化加细、抑制、微聚集、敏感属性分箱、缺失编码治理、外部信息清单复核），并在影子策略验证后排期切换；工具本身不产生策略变更。

## 局限

- 总体唯一性依赖“发布表是总体的随机抽样”假设；便利样本下应以全表精确指标为准。
- 攻击者画像是清单输入：外部信息盘点不全时结果会偏乐观，清单变更应重跑。
- 稀有度阈值（≤3 次）与 k、l 底线是策略参数，可在清单中调整，阈值与每次结论一并留痕。
- 当前仅支持 CSV 类分隔文本（与无第三方依赖的部署约束一致）。
